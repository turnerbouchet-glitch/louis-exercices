# Les exercices de Louis

Pages d'exercices interactives de Louis, publiées avec GitHub Pages :
https://turnerbouchet-glitch.github.io/louis-exercices/

## Méthode (Caroline, Nicolas et leur Claude)

1. Créer l'exercice (version élève .html + corrigé .md) et l'enregistrer dans le dossier iCloud partagé
   « Louis - Exercice Claude partagé », dans le dossier de la matière, nommé `AAAA-MM-JJ - Sujet - élève` / `- corrigé`.
2. Copier la version élève (.html) dans ce dépôt, dans le dossier de la matière, avec un nom court sans accents ni espaces :
   `allemand/`, `anglais/`, `francais/`, `sciences/`, `geographie/`, `histoire/`, `math/`
   (ex. `sciences/fleur-au-fruit.html`). Ajouter `<meta name="robots" content="noindex">` dans le `<head>`.
3. Ajouter un lien vers la page dans `index.html` (section de la matière).
4. Publier (commit + push sur `main`) : la page est en ligne après 1 à 2 minutes.
5. Ajouter une ligne dans Notion (Le QG de Louis > 🎯 Exercices) avec l'adresse de la page dans la colonne **Lien**
   (et un bouton « Ouvrir » dans la fiche).
6. Mettre à jour le `Suivi - <matière>.md` et le Journal de `Memory - partagé.md`.

Les corrigés ne vont **pas** dans ce dépôt : il est public. Pas de nom de famille, d'adresse ni de photo de Louis.
Les étoiles sont gardées dans le navigateur de l'ordinateur où Louis joue.
